# Geographic outlines

`ne_110m_land.geojson` is the Natural Earth 1:110m land dataset, bundled for
offline vector maps in PDF exports. Natural Earth data are public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

The PDF uses a latitude/longitude overview with a central-meridian shift, clipped
search circles and the sampled short great-circle route. It does not retrieve or
reproduce the interactive map's third-party raster tiles.
